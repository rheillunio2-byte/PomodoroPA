# Contributing to FocusFlow

Thank you for your interest in contributing to **FocusFlow**! Contributions, suggestions, bug fixes, and feature enhancements are greatly appreciated.

## How to Contribute

Follow these steps to contribute to the project:

### 1. Fork the Repository

Create your own copy of the repository by clicking the **Fork** button on GitHub.

### 2. Clone Your Fork

```bash
git clone https://github.com/your-username/FocusFlow.git
```

### 3. Create a New Branch

```bash
git checkout -b feature/your-feature-name
```

### 4. Make Your Changes

You may:

* Fix bugs
* Improve the user interface
* Add new productivity features
* Optimize performance
* Improve documentation
* Refactor existing code

### 5. Test Your Changes

Before submitting your contribution, ensure that:

* The application runs without errors.
* Existing features continue to work correctly.
* New functionality has been tested thoroughly.

### 6. Commit Your Changes

```bash
git add .
git commit -m "Describe your changes"
```

### 7. Push Your Branch

```bash
git push origin feature/your-feature-name
```

### 8. Submit a Pull Request

Create a Pull Request (PR) describing:

* What you changed
* Why the change is needed
* Any screenshots (if UI changes were made)

# Development Guidelines

To maintain a clean and maintainable codebase, please follow these practices:

* Write clean, readable, and modular Python code.
* Follow consistent naming conventions.
* Keep functions focused on a single responsibility.
* Add comments where complex logic is implemented.
* Avoid unnecessary dependencies.
* Follow the existing project structure.
* Test all new features before submission.

---

# Reporting Bugs

If you discover a bug, please open a GitHub Issue and include:

* A clear description of the problem
* Steps to reproduce the issue
* Expected behavior
* Actual behavior
* Screenshots (if applicable)
* Python version
* Operating system
* Error messages or logs (if available)

---

# Suggesting Features

New ideas are always welcome.

When proposing a feature, please include:

* A detailed feature description
* The problem it solves
* Expected benefits
* Possible implementation ideas (optional)

Examples include:

* AI-powered study recommendations
* Goal tracking
* Habit analytics
* Cloud synchronization
* Focus music integration
* Weekly productivity reports

---

# Code Style

FocusFlow follows these development practices:

* Python 3.x compatibility
* CustomTkinter for the graphical user interface
* SQLite for local data storage
* Modular project architecture
* Meaningful variable and function names
* Consistent formatting and documentation

---

# Pull Request Checklist

Before submitting your Pull Request, ensure that:

* ✔ Code builds successfully
* ✔ No existing functionality is broken
* ✔ New features are tested
* ✔ Documentation is updated (if necessary)
* ✔ Commit messages are clear and descriptive
